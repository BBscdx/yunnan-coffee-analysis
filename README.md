# 云南咖啡产业数据分析：从田间到杯中

> 一条咖啡产业链的数据观察：产在云南，喝在贵阳。

## 背景与问题

云南产全国 98% 的豆、贵阳 3000+ 家店不产一颗豆、2026 年价格从 61 回落到 45。

基于真实数据回答下列问题：
1. 云南各产区的种植面积、产量变化趋势、内外销比例变化。
2. 贵阳咖啡店门店密度为什么超上海？这些门店里连锁品牌多少？独立精品咖啡馆多少？
3. 价格周期怎么走？精品豆为什么抗跌？

探讨下列问题：
1. 贵阳能不能成为烘焙枢纽？
2. 云南到贵阳之间缺少的是哪一环？云南能否直接对接贵阳？

## 开发方式

借助 AI 工具（Claude Code）完成：Python 代码生成、辅助检索。
个人独立完成：需求与问题定义、SQL 建库与查询、数据收集与溯源、Python 代码逐行校验与修改、结论与讲解。
质量保证：每个数据点回查原始出处，标注口径，缺口照实记录。
